# Dexter vs CCX (Claude Code) 差距分析与发展规划

**日期**: 2026-05-07
**版本**: 2.0

---

## 1. 概述

本文档深入分析 **Dexter** 与 **CCX** (Claude Code) 之间的架构差距，并制定详细的发展计划。

### 核心发现

| 维度 | Dexter 优势 | Dexter 劣势 |
|------|------------|------------|
| **Agent 核心** | 三层上下文压缩、异步生成器 | 无 Subagent、无 Coordinator |
| **工具系统** | 23个工具、金融领域专用 | 静态注册、无动态加载 |
| **内存系统** | 向量+关键词混合搜索、MMR | 无文件内存、会话内存 |
| **后台处理** | Cron 定时任务 | 无 Daemon/Worker |
| **MCP** | 无 | 完整 MCP 客户端(5种传输) |
| **多Agent** | 无 | Coordinator 模式、Team 系统 |
| **权限系统** | 基础审批 | 规则+分类器 |
| **Hooks** | 无 | 10+ 生命周期钩子 |
