## 内置技能

### 1. MedFish (医疗器械/医药)

医疗器械和医药行业分析。

**能力:**
- 医疗器械分类
- 医药行业研究
- 体外诊断 (IVD) 分析
- CXO 行业分析
- A股医疗公司财报

### 2. Technical Analysis (技术分析)

技术指标计算和图表分析。

**能力:**
- RSI (相对强弱指数)
- MACD (移动平均收敛发散)
- 布林带 (Bollinger Bands)
- 均线系统 (MA5, MA10, MA20, MA60)
- KDJ 指标
- 成交量分析

### 3. Backtesting (回测引擎)

策略回测和性能分析。

**能力:**
- 策略回测
- 夏普比率计算
- 最大回撤分析
- 收益统计
- 交易信号生成

### 4. Risk Management (风险管理)

风险计算和头寸管理。

**能力:**
- 波动率计算
- 头寸限制
- 止损策略
- 风险敞口
- 相关性分析

### 5. Sentiment Analysis (舆情分析)

新闻情感和公众舆论分析。

**能力:**
- 新闻情感分析
- 机构持仓追踪
- 分析师评级
- 内部交易监控

### 6. Financial Data (金融数据)

金融数据获取和处理。

**能力:**
- 股票价格
- 财务报表
- 资金流向
- 估值指标
- 宏观数据

### 7. Fundamental Analysis (基本面分析)

公司基本面分析。

**能力:**
- 盈利能力分析
- 成长性评估
- 财务健康诊断
- 运营效率
