# 权限系统

> 多层权限架构保障安全运行

## 概述

UpUp 实现了参考 Claude Code 的全面权限系统，提供多层保护：

```
┌─────────────────────────────────────────────────────────────────────┐
│                    权限系统层级                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  第1层: 会话模式                                                   │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  • default      → 敏感工具标准审批                          │   │
│  │  • .accept-all  → 接受所有提示                            │   │
│  │  • bypass       → 绕过所有权限检查                        │   │
│  │  • dangerously  → 允许危险操作                           │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                   │
│  第2层: 工具权限                                                  │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  • bypass  → 始终允许                                    │   │
│  │  • ask     → 需要用户审批                                │   │
│  │  • deny    → 始终阻止                                   │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                   │
│  第3层: 命令分类                                                  │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Bash 命令按类型分类:                                      │   │
│  │  • read      → cat, grep, find (bypass)                 │   │
│  │  • write     → mkdir, rm, cp (ask)                       │   │
│  │  • dangerous → sudo, chmod (deny)                        │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

---

## 权限模式

### 会话模式

```typescript
type PermissionMode =
  | 'default'           // 标准权限检查
  | '.accept-all'       // 接受所有提示
  | 'bypassPermissions' // 绕过所有权限检查
  | 'dangerously';      // 允许危险操作
```

### 工具模式

```typescript
type ToolPermissionMode =
  | 'bypass'  // 始终允许
  | 'ask'     // 需要用户审批
  | 'deny';   // 始终阻止
```

## 内置规则

### 自动放行 (无需审批)

| 类别 | 命令 |
|------|------|
| **导航** | `pwd`, `cd`, `ls`, `ll`, `la` |
| **读取** | `cat`, `head`, `tail`, `less`, `more` |
| **搜索** | `grep`, `find`, `which`, `wc`, `diff` |
| **Git (读)** | `git status`, `git log`, `git diff`, `git show` |
| **信息** | `echo`, `date`, `whoami`, `hostname` |

### 需要审批

| 类别 | 命令 |
|------|------|
| **写入** | `mkdir`, `touch`, `rm`, `cp`, `mv` |
| **编辑** | `sed`, `awk`, `tee` |
| **Git (写)** | `git commit`, `git push`, `git merge` |
| **安装** | `npm install`, `pip install` |

### 始终拒绝

| 类别 | 命令 |
|------|------|
| **系统** | `sudo`, `su`, `chmod 777`, `chmod 000` |
| **网络** | `curl` 敏感头 |
| **危险** | `rm -rf /`, `mkfs` |
