## 4. Shell 命令执行架构

### 4.1 Shell 命令执行流程

```
+=========================================================================+
|                    Shell 命令执行详细流程                                 |
+=========================================================================+

+-------------------------------------------------------------------------+
|                     promptShellExecution.ts                               |
|                                                                          |
|    executeShellCommandsInPrompt(text, context, skillName)               |
|                                                                          |
|    +--------------------------------------------------------------------+
|    |                    第一阶段: 正则匹配                                  |
|    |                                                                     |
|    |   +------------------------------------------------------------+  |
|    |   | 正则模式                  | 匹配内容                       |  |
|    |   | +------------------------------------------------------------+  |
|    |   | | ```! ... ```            | Loucode 代码块               |  |
|    |   | | ```bash ... ```        | 标准 bash 代码块             |  |
|    |   | | ```shell ... ```       | 标准 shell 代码块            |  |
|    |   | | ```!ps ... ```         | PowerShell 代码块           |  |
|    |   | | !`...`                 | Loucode 内联                |  |
|    |   | | !ps`...`              | PowerShell 内联            |  |
|    |   | +------------------------------------------------------------+  |
|    |   |                                                                     |  |
|    |   |   匹配结果: [{ pattern, command, isInline, shell }]               |  |
|    |   |                                                                     |  |
|    +--------------------------------------------------------------------+
|                                     |                                    |
|                                     v                                    |
|    +--------------------------------------------------------------------+
|    |                    第二阶段: 权限检查                                 |
|    |                                                                     |
|    |   +------------------------------------------------------------+  |
|    |   | 1. 从 context.getAppState() 获取权限配置               |  |
|    |   | 2. 检查 alwaysAllowRules.command                      |  |
|    |   | 3. 匹配规则:                                           |  |
|    |   |      - Bash(curl*)      -> curl 开头的命令允许          |  |
|    |   |      - Bash(python3*)  -> python3 开头的命令允许     |  |
|    |   |      - Read            -> 读取文件允许               |  |
|    |   +------------------------------------------------------------+  |
|    |                                                                     |
|    |   +------------------------------------------------------------+  |
|    |   | if (!allowed) throw MalformedCommandError             |  |
|    |   +------------------------------------------------------------+  |
|    |                                                                     |
|    +--------------------------------------------------------------------+
|                                     |                                    |
|                                     v                                    |
|    +--------------------------------------------------------------------+
|    |                    第三阶段: 命令执行                                 |
|    |                                                                     |
|    |   +------------------------------------------------------------+  |
|    |   | shell === 'powershell'                              |  |
|    |   |      |                                               |  |
|    |   |      +-- TRUE  -> executePowerShellCommand()        |  |
|    |   |      |                                               |  |
|    |   |      +-- FALSE -> executeBashCommand()             |  |
|    |   |               |                                      |  |
|    |   |               +-- timeout: 30000ms                  |  |
|    |   |                   capture stdout/stderr               |  |
|    |   +------------------------------------------------------------+  |
|    |                                                                     |
|    |   执行结果: { stdout, stderr, exitCode, shell }                   |
|    |                                                                     |
|    +--------------------------------------------------------------------+
|                                     |                                    |
|                                     v                                    |
|    +--------------------------------------------------------------------+
|    |                    第四阶段: 结果替换                               |
|    |                                                                     |
|    |   result = result.replace(pattern, () => output)                   |
|    |                                                                     |
|    |   +------------------------------------------------------------+  |
|    |   | 输入: "查询结果: ```! echo hi``` 完成"              |  |
|    |   | 命令: "echo hi"                                    |  |
|    |   | 输出: "hi"                                        |  |
|    |   | -------------------------------------------------------- |  |
|    |   | 结果: "查询结果: hi 完成"                           |  |
|    |   +------------------------------------------------------------+  |
|    |                                                                     |
|    +--------------------------------------------------------------------+
|                                                                          |
+-------------------------------------------------------------------------+
```

### 4.2 正则模式详解

```
+=========================================================================+
|                       支持的正则模式                                      |
+=========================================================================+

+-------------------------------------------------------------------------+
|  Loucode 风格 (原有)                                                    |
+-------------------------------------------------------------------------+

  代码块:   ```! <命令> ```
  正则:     /```!\\s*\\n?([\\s\\S]*?)\\n?```/g
  示例:     ```!
            curl -s api.example.com
            ```

  内联:     !`<命令>`
  正则:     /(?<=^|\\s)!`([^`]+)`/gm
  示例:     运行 !`curl api` 获取数据

+-------------------------------------------------------------------------+
|  PowerShell 风格 (原有)                                                |
+-------------------------------------------------------------------------+

  代码块:   ```!ps <命令> ```
  正则:     /```!ps\\s*\\n?([\\s\\S]*?)\\n?```/g
  示例:     ```!ps
            Get-Process
            ```

  内联:     !ps`<命令>`
  正则:     /(?<=^|\\s)!ps`([^`]+)`/gm
  示例:     运行 !ps`Get-Service` 查看服务

+-------------------------------------------------------------------------+
|  标准 Markdown 风格 (新增 v3.0)                                          |
+-------------------------------------------------------------------------+

  Bash 代码块:   ```bash <命令> ```
  正则:         /```bash\\s*\\n?([\\s\\S]*?)\\n?```/gi
  示例:         ```bash
                python3 -c "import akshare; print('ok')"
                ```

  Shell 代码块:   ```shell <命令> ```
  正则:         /```shell\\s*\\n?([\\s\\S]*?)\\n?```/gi
  示例:         ```shell
                ls -la
                ```

+-------------------------------------------------------------------------+
```

## 5. 权限系统架构

### 5.1 权限检查流程

```
+=========================================================================+
|                       权限检查流程                                      |
+=========================================================================+

+-------------------------------------------------------------------------+
|                      权限检查入口                                       |
|                                                                          |
|    hasPermissionsToUseTool(tool, input, context, ...)                  |
|                                                                          |
|    输入:                                                                |
|    +--------------------------------------------------------------------+
|    | tool: { name: "bash" }                                            |
|    | input: { command: "curl -s https://api.example.com" }            |
|    | context.getAppState().toolPermissionContext                        |
|    |   .alwaysAllowRules.command                                       |
|    +--------------------------------------------------------------------+
|                                                                          |
+-------------------------------------------------------------------------+
                                     |
                                     v
+-------------------------------------------------------------------------+
|                       规则匹配引擎                                      |
|                                                                          |
|    allowedRules = [                                                    |
|      "Bash(curl*)",       <- 通配符匹配                               |
|      "Bash(python3*)",    <- 通配符匹配                               |
|      "Bash(wget*)",       <- 通配符匹配                               |
|      "Read",              <- 精确匹配                                  |
|      "Write(/tmp/*)"      <- 路径匹配                                 |
|    ]                                                                     |
|                                                                          |
|    匹配算法:                                                           |
|    +--------------------------------------------------------------------+
|    | 1. 解析规则: /ToolName(Pattern)/                               |  |
|    |    - ToolName: bash, Read, Write, etc.                         |  |
|    |    - Pattern: curl*, /tmp/*, etc.                             |  |
|    |                                                                     |  |
|    | 2. 工具名匹配 (大小写不敏感)                                     |  |
|    |    - "bash" matches "Bash"                                     |  |
|    |                                                                     |  |
|    | 3. 命令匹配                                                       |  |
|    |    - "curl*" -> startsWith("curl")                            |  |
|    |    - "/tmp/*" -> startsWith("/tmp/")                           |  |
|    |    - 无 * -> 精确匹配                                           |  |
|    +--------------------------------------------------------------------+
|                                                                          |
+-------------------------------------------------------------------------+
                                     |
                                     v
+-------------------------------------------------------------------------+
|                       权限结果                                          |
|                                                                          |
|    { behavior: "allow" | "deny" | "ask", message?: string }           |
|                                                                          |
|    +--------------------------------------------------------------------+
