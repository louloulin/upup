# Macroeconomic Analysis Skill

## Overview

Analyze macroeconomic factors affecting investments: GDP, inflation, interest rates, and policy.

## Key Indicators

| Indicator | Description | Impact |
|-----------|-------------|--------|
| GDP | Economic growth | Positive |
| CPI | Inflation | Negative when high |
| PMI | Business activity | Positive |
| Interest Rate | Cost of money | Asset prices |
| Yuan/USD | Currency | Export/Import |
