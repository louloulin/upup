# 股票深度分析

## 使用场景

当用户需要对某只股票进行综合分析时使用此技能。适用于以下场景：

- 用户想了解某只股票的投资价值和综合评级
- 用户需要查看K线走势图数据，分析走势形态
- 用户想查看财务指标，评估公司基本面
- 用户希望获得多维度综合分析报告，辅助投资决策
- 用户问"这只股票怎么样""是否值得买入"等投资咨询类问题

## 工作流程

### Step 1: 获取股票代码

从用户输入中提取股票代码或名称：
- A股代码：6位数字（沪市600xxx，深市000xxx/300xxx）
- 港股代码：5位数字 + .HK（如00700.HK）
- 美股代码：英文缩写（如AAPL）

如果不确定代码，使用 `stock_search` 或 `search` 搜索。

### Step 2: 多维度数据采集

调用以下工具获取数据（可并行）：

1. **行情数据**：`get_astock_price({ code })`
   - 返回：实时价格、涨跌幅、成交量、市值等

2. **K线数据**：`get_technical_data({ code })`
   - 返回：MA均线、MACD、KDJ、RSI、布林带等技术指标

3. **财务数据**：`get_astock_financials({ code })`
   - 返回：PE、PB、ROE、营收增长率、净利润等

4. **新闻舆情**：`get_astock_news({ code })`
   - 返回：最新新闻、公告、研报等

### Step 3: 综合评分计算

根据采集的数据计算综合评分：

```
技术面评分 = (均线形态 × 0.3) + (MACD信号 × 0.3) + (KDJ状态 × 0.2) + (RSI状态 × 0.2)
基本面评分 = (估值合理性 × 0.4) + (盈利能力 × 0.3) + (成长性 × 0.3)
综合评分 = 技术面评分 × 0.4 + 基本面评分 × 0.6
```

### Step 4: 生成分析报告

将各维度数据整合成结构化的分析报告。

## 工具说明

### get_astock_price
获取A股/港股/美股实时行情数据。

参数：
- `code`: 股票代码（如 600519.SH, 00700.HK）

### get_technical_data
获取股票技术指标数据。

参数：
- `code`: 股票代码
- `period`: 周期（可选，默认为日K）

### get_astock_financials
获取股票财务指标数据。

参数：
- `code`: 股票代码

### get_astock_news
获取股票相关新闻和公告。

参数：
- `code`: 股票代码
- `limit`: 返回数量（默认10条）
