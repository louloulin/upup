# 智能选股筛选

## 使用场景

当用户需要根据特定条件筛选股票时使用此技能。适用于以下场景：

- 用户想筛选MACD金叉、KDJ超卖等技术指标的股票
- 用户想查找涨停、跌停、放量上涨等特定走势的股票
- 用户想根据估值、成长性等基本面条件筛选
- 用户想进行多条件组合选股
- 用户需要快速从大量股票中找到符合策略的标的

## 选股维度

### 技术面筛选

| 指标 | 选项 | 说明 |
|-----|------|------|
| MACD | 金叉/死叉/背离 | 趋势转折信号 |
| KDJ | 超买/超卖/金叉/死叉 | 动量指标 |
| RSI | 超买(>70)/超卖(<30) | 相对强弱指标 |
| 均线 | 多头排列/空头排列/均线缠绕 | 趋势判断 |
| 布林带 | 上轨突破/下轨支撑/收口 | 波动率指标 |
| 成交量 | 放量/缩量/地量 | 量能变化 |

### 基本面筛选

| 指标 | 选项 | 说明 |
|-----|------|------|
| 市盈率(PE) | 范围筛选 | 估值水平 |
| 市净率(PB) | 范围筛选 | 估值水平 |
| 净资产收益率(ROE) | >X% | 盈利能力 |
| 营收增长率 | >X% | 成长能力 |
| 净利润增长率 | >X% | 成长能力 |
| 毛利率 | >X% | 盈利质量 |

### 行情筛选

| 指标 | 选项 | 说明 |
|-----|------|------|
| 涨跌幅 | 范围筛选 | 价格变化 |
| 换手率 | >X% | 交易活跃度 |
| 成交量 | 放量N倍 | 量能变化 |
| 流通市值 | 范围筛选 | 盘口大小 |
| 股价 | 范围筛选 | 价格区间 |

## 工作流程

### Step 1: 解析筛选条件

将用户的自然语言条件转换为结构化筛选参数。

示例转换：
- "MACD金叉" → `macd_signal: 'golden_cross'`
- "PE低于20" → `pe_max: 20`
- "流通市值50亿以下" → `float_market_cap_max: 50`

### Step 2: 执行筛选

调用选股工具获取符合条件的股票列表。

### Step 3: 结果排序

按相关度、涨跌幅、成交量等指标排序。

### Step 4: 生成报告

## 常见选股场景

### 场景1: 寻找强势股
```
筛选条件：
- 均线多头排列
- MACD金叉
- 涨幅 > 3%
- 换手率 > 5%
```

### 场景2: 超跌反弹
```
筛选条件：
- KDJ超卖（J < 20）
- RSI < 30
- 跌幅 > 5%
- 成交量放大
```

### 场景3: 价值投资
```
筛选条件：
- PE < 20
- PB < 3
- ROE > 15%
- 净利润增长 > 10%
```

### 场景4: 突破形态
```
筛选条件：
- 股价突破20日均线
- 成交量超过20日均量2倍
- 涨幅 > 5%
- MACD在水上
```

## 选股策略模板

### 趋势跟踪策略
```
{
  trend: 'up',
  ma_signal: 'bullish',
  macd_signal: 'golden_cross',
  volume_ratio_min: 1.5,
  price_change_min: 2
}
```

### 价值投资策略
```
{
  pe_max: 25,
  pb_max: 3,
  roe_min: 15,
  profit_growth_min: 10,
  debt_ratio_max: 60
}
```

### 短线投机策略
```
{
  turnover_min: 10,
  volume_ratio_min: 2,
  price_change_min: 3,
  kdj_signal: 'oversold'
}
```

## 工具说明

### screen_astocks
根据条件筛选A股。

参数：
- `macd_signal`: MACD信号（golden_cross/dead_cross）
- `kdj_signal`: KDJ信号（overbought/oversold）
- `ma_signal`: 均线信号（bullish/bearish）
- `price_change_min/max`: 涨跌幅范围
- `volume_ratio`: 量比
- `turnover_min/max`: 换手率范围
- `pe_min/max`: 市盈率范围
- `market`: 市场（sh/sz/all）

### get_technical_data
获取技术指标数据。

参数：
- `code`: 股票代码
- `period`: 周期
