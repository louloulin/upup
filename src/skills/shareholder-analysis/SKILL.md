# Shareholder Analysis Skill

## Overview

Analyze shareholder structure to understand ownership and potential price movements.

## Key Metrics

| Metric | Interpretation |
|--------|----------------|
| 股东户数 | 户数增加=分散，减少=集中 |
| 户均持股 | 越大越集中 |
| 前十大股东 | 机构持仓比例 |
| 筹码分布 | 成本集中区间 |
