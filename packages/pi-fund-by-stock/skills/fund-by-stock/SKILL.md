# Fund-by-Stock 反向搜索技能

## 能力

通过股票代码 / 名称反查**公募基金的重仓情况**，解决 3 类问题：

1. **评估"抱团"程度**：某只股票被多少只基金重仓？总持仓占比多少？
2. **找同主题基金**：看好某只股票后，找出其他"持仓类似"的基金做组合
3. **基金尽调**：已知基金代码，列出其前 N 大重仓股

## 工作流程

### 场景 A：股票 → 基金（最常用）

```
用户问：哪些基金重仓了贵州茅台？
         ↓
Step 1: fund_search_by_stock({ query: '贵州茅台', limit: 20 })
         ↓
Step 2: 按持仓占比降序输出清单
         ↓
Step 3: （可选）追问 → 调用 fund_heavy_holdings 验证单只基金
```

### 场景 B：基金 → 股票

```
用户问：005827 易方达蓝筹精选都买了什么？
         ↓
Step 1: fund_heavy_holdings({ fund_code: '005827', top_n: 10 })
         ↓
Step 2: 直接输出前 10 大重仓
```

### 场景 C：快速评估抱团

```
用户问：宁德时代被基金重仓的程度？
         ↓
Step 1: fund_holders_count({ query: '300750.SZ' })
         ↓
Step 2: 一句话结论：N 只基金重仓，总占比 X%
```

## 输入规范

| 输入类型 | 例子 | 说明 |
|---------|------|------|
| A 股代码 | `600519.SH` / `000858.SZ` | 推荐，速度快 |
| A 股名称 | `贵州茅台` / `茅台` | 中文名 |
| 港股代码 | `00700.HK` | 5 位代码 |
| 港股名称 | `腾讯` / `腾讯控股` | 中文名 |

## 输出规范

返回的格式（Markdown）：
- 命中数 + 持仓占比总和
- 基金清单（按 valuePercent 降序）
- 标记 "前 10 重仓" 标签
- 数据快照日期 + 风险提示

## 常用追问模板

| 用户意图 | 推荐追问 |
|---------|---------|
| 想看更多 | `fund_search_by_stock({ limit: 50 })` |
| 只看核心持仓 | `fund_search_by_stock({ top10_only: true })` |
| 过滤低暴露 | `fund_search_by_stock({ min_value_percent: 3 })` |
| 验证某只基金 | `fund_heavy_holdings({ fund_code: '005827' })` |

## 与其他工具的联动

- 想给某只基金做估值 → 拿到 `fundCode` 后 → 用 `get_astock_financials` 或 `dcf_model`
- 想看股票本身 → 用 `get_market_data` 或 `stock_screener`
- 想跟同行对比 → 用 `fund_compare`

## 限制

- 数据基于 UpUp 离线快照，**非实时**
- 港股 / 美股基金持仓披露滞后，可能未及时反映最新季报
- 股票名称歧义时（如"茅台"vs"贵州茅台"），优先用全称
- 仅公募基金，不含私募、ETF 申赎篮子

## 示例对话

```
> "哪些基金重仓了贵州茅台？"

→ 调用 fund_search_by_stock({ query: '贵州茅台', limit: 20 })
→ 返回 20 只重仓茅台的基金清单
   1. 易方达蓝筹精选混合（005827）— 8.20%
   2. 易方达消费行业股票（110022）— 7.xx%
   ...

> "005827 还买了什么？"

→ 调用 fund_heavy_holdings({ fund_code: '005827', top_n: 10 })
→ 返回前 10 大重仓股
   1. 贵州茅台 — 8.20%
   2. 五粮液 — 6.40%
   ...
```
