# DCA 回测技能

执行基金定投回测，分析定投策略的历史表现。

## 支持的基金类型

| 类型 | 说明 | 适用策略 |
|------|------|----------|
| 股票型 | 高波动 | DCA优选 |
| 混合型 | 中波动 | DCA优选 |
| 指数型 | 跟踪指数 | DCA优选 |
| 债券型 | 低波动 | 不推荐DCA |
| 货币型 | 稳定 | 不需要DCA |

## 回测参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 回测月数 | 12 | 1-60个月 |
| 每月金额 | 1000元 | 100-100000 |
| 定投日 | 每月1日 | 1-28日 |

## Step 1: 选择基金

使用 `fund_search` 搜索基金:

```
Call: fund_search({ keyword: "易方达消费" })
```

## Step 2: 执行回测

使用 `backtest_dca` 执行DCA回测:

```
Call: backtest_dca({
  fund_code: "110022",
  months: 12,
  monthly_amount: 1000
})
```

## Step 3: 分析结果

回测报告包含:

- **收益表现**: 总投入、最终市值、总收益、总收益率
- **交易统计**: 买入次数、卖出次数、平均成本
- **风险指标**: 最大回撤、波动率、夏普比率

## Step 4: 策略建议

根据回测结果给出建议:

| 指标 | 优秀 | 良好 | 较差 |
|------|------|------|------|
| 总收益率 | >20% | 5-20% | <5% |
| 最大回撤 | <10% | 10-20% | >20% |
| 夏普比率 | >1.0 | 0.5-1.0 | <0.5 |

## 策略优化建议

### 调整定投金额
- 市场下跌时增加定投
- 市场上涨时减少定投

### 调整定投频率
- 高波动基金: 双周或周投
- 低波动基金: 月投即可

### 长期坚持
- DCA需要3-5年才能看到明显效果
- 短期波动不代表策略失败

## 注意事项

1. **模拟数据**: 当前回测使用模拟历史数据，实际使用时调用真实API
2. **费率假设**: 默认申购费率0.1%
3. **仅供参考**: 过去业绩不代表未来表现
4. **风险提示**: 定投也有亏损风险，请谨慎
