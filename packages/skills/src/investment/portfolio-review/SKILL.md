# 投资组合复盘

## 使用场景

当用户需要分析投资组合表现或复盘交易决策时使用此技能。适用于以下场景：

- 用户想查看当前持仓的整体盈亏情况
- 用户想了解各持仓股票的详细表现
- 用户需要资产配置建议和仓位调整策略
- 用户想复盘历史交易，总结经验教训
- 用户想评估投资组合的风险暴露

## 工作流程

### Step 1: 收集持仓信息

获取用户的持仓数据：
- 持仓股票列表
- 买入价格和数量
- 当前市场价格
- 持仓时间

如果没有自动获取渠道，引导用户输入或导入持仓数据。

### Step 2: 计算盈亏数据

对每个持仓计算：
```
当日盈亏 = (当前价 - 昨日收盘价) × 持仓数量
持仓盈亏 = (当前价 - 买入价) × 持仓数量
盈亏比例 = (当前价 - 买入价) / 买入价 × 100%
持仓市值 = 当前价 × 持仓数量
```

### Step 3: 风险评估

计算组合层面的风险指标：
- 总风险暴露
- 行业集中度
- 单一股票仓位上限
- 相关性风险

### Step 4: 生成复盘报告

整合所有数据生成结构化报告。

## 持仓数据格式

支持以下方式获取持仓数据：

1. **手动输入**：
```
我的持仓：
- 贵州茅台 600519.SH: 100股，成本价1800元
- 宁德时代 300750.SZ: 200股，成本价380元
```

2. **配置文件**：在 `.dexter/portfolio.json` 中配置
```json
{
  "positions": [
    {
      "code": "600519.SH",
      "name": "贵州茅台",
      "quantity": 100,
      "costPrice": 1800
    }
  ]
}
```

3. **券商API**：如已配置券商数据源，自动获取

## 工具说明

### calculate_position_metrics
计算单个持仓的详细指标。

参数：
- `code`: 股票代码
- `quantity`: 持仓数量
- `costPrice`: 成本价

### assess_portfolio_risk
评估投资组合整体风险。

参数：
- `positions`: 持仓列表
- `confidenceLevel`: 置信水平（默认0.95）
