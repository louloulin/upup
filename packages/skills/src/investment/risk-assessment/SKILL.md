# 投资风险评估

## 使用场景

当用户需要评估和控制投资风险时使用此技能。适用于以下场景：

- 用户想了解当前持仓的整体风险水平
- 用户需要设置合理的止损位
- 用户想计算投资组合的VaR风险价值
- 用户想评估最大可能亏损
- 用户想进行风险排查和预警

## 核心风险指标

### 1. VaR (Value at Risk) 风险价值

衡量在给定置信水平下，投资组合在特定时间内可能遭受的最大损失。

```
VaR(95%, 1日) = 投资组合价值 × 波动率 × 1.65
```

解读：95%置信度下，每日最大损失不会超过VaR值。

### 2. CVaR (Conditional VaR) 条件风险价值

超过VaR阈值的平均损失，更保守的风险度量。

### 3. 最大回撤 (Max Drawdown)

从历史最高点到最低点的最大跌幅。

### 4. 夏普比率 (Sharpe Ratio)

风险调整后的收益指标。

```
夏普比率 = (组合收益 - 无风险收益) / 组合波动率
```

### 5. 波动率 (Volatility)

资产价格的变动程度，通常用标准差衡量。

## 工作流程

### Step 1: 收集持仓数据

获取用户持仓信息（股票代码、数量、成本价）。

### Step 2: 获取市场数据

获取各持仓股票的历史波动率：
- 历史价格数据
- 日收益率计算
- 波动率估算

### Step 3: 计算风险指标

```
# 单只股票风险
单股VaR = 持仓市值 × 波动率 × Z值(置信度)

# 组合风险（假设不相关）
组合VaR = √(Σ 单股VaR²)

# 组合VaR（考虑相关性）
组合VaR = √(w' × Σ × w)
其中 Σ 为协方差矩阵，w 为权重向量
```

### Step 4: 风险分级

根据综合评分确定风险等级：

| 等级 | 评分范围 | 说明 |
|-----|---------|------|
| 🟢 低风险 | 80-100 | 风险可控，稳健运营 |
| 🟡 中低风险 | 60-80 | 风险适中，需关注 |
| 🟠 中高风险 | 40-60 | 风险偏高，建议调整 |
| 🔴 高风险 | 0-40 | 风险过大，需立即调整 |

### Step 5: 生成风险报告

## 风险指标计算公式

### 历史波动率
```
σ = √(Σ(ri - r̄)² / (n-1))
其中 ri 为日收益率，r̄ 为平均收益率，n 为天数
```

### 组合波动率
```
σp = √(Σ wi² × σi² + 2Σ wi × wj × σi × σj × ρij)
```

### VaR (参数法)
```
VaR = V0 × σ × Zα
其中 Zα 为置信度对应的Z分数（95%: 1.65, 99%: 2.33）
```

## 止损位计算方法

| 止损方式 | 公式 | 适用场景 |
|---------|------|---------|
| 固定比例 | 买入价 × (1 - 比例) | 短线操作 |
| 移动止损 | 最高价 × (1 - 比例) | 趋势跟踪 |
| 技术止损 | 均线/K线支撑位 | 技术分析 |
| 时间止损 | 持有N天后强制止损 | 短线策略 |

## 工具说明

### calculate_portfolio_risk
计算投资组合风险指标。

参数：
- `positions`: 持仓列表 [{code, quantity, costPrice}]
- `confidenceLevel`: 置信水平（默认0.95）
- `historicalDays`: 历史数据天数（默认30）

### calculate_stop_loss
计算止损位。

参数：
- `code`: 股票代码
- `entryPrice`: 买入价格
- `method`: 止损方法（fixed/moving/technical）
- `buffer`: 安全缓冲比例（默认5%）
