# Valuation Alert Skill

## Overview

Set valuation-based alerts for price targets and valuation thresholds.

## Alert Types

| Type | Description |
|------|-------------|
| PE 警告 | PE超过历史X%分位 |
| PB 警告 | PB超过历史X%分位 |
| 价格目标 | 达到目标价格 |
| 异动提醒 | 估值异常波动 |
