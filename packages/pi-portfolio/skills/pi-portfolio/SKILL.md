# Pi Portfolio

- Separate portfolio observations, benchmark observations, and attribution assumptions.
- Report allocation, selection, interaction, factor contributions, sector contributions, active return, and residual explicitly.
- Preserve the selected sector classification and evidence IDs.
- Treat attribution as historical explanation, never as a forecast or automatic rebalance instruction.
- Do not place, modify, or cancel orders from this package.
