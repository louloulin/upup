# 期货价格结构交易系统 SOP

按 4 个阶段顺序执行，每阶段失败则不进入下一阶段。

## 阶段 1：周线判方向

调用 `price_structure_analyze_direction`：

- **多头结构**：周线创新低 + 阳线基线 + 连续 3 根高于基线 + 第 3 根为创新高阳线
- **空头结构**：镜像
- **见顶结构**：多头结构 + 价格创新高后第 2 次收盘价低于创新高阳线
- **见底结构**：镜像

判定：
- 多头结构 + 未见顶 → **看多**
- 空头结构 + 未见底 → **看空**
- 其他 → **震荡（不开仓）**

## 阶段 2：日线找拐点

按阶段 1 判定的方向调用 `price_structure_entry_signal`：

- **看多**：找回调拐点（多头结构创新高 → 收盘价创新低阴线 → 创新低 → 首根收盘价高于阴线最高价的阳线）
- **看空**：找反弹拐点（镜像）
- 未找到 → **不开仓**

## 阶段 3：止损止盈

入场信号工具自动输出：

- **止损**：多单 = 回调拐点最低点；空单 = 反弹拐点最高点
- **止盈**：
  - 多单：回调拐点后"创新低 → 收盘价创新低阴线 → 收盘价创新高阳线"序列中创新高阳线的最低价
  - 空单：镜像

## 阶段 4：风控校验（强制）

调用 `price_structure_risk_check` 或 `price_structure_run_sop`：

- 单次开仓 **1 手**
- 预估亏损 = |入场价 - 止损价| × 合约乘数 × 1
- 必须在 **[10, 2000] 元** 区间内
- 不满足 → **不开仓**

## 工具调用顺序（推荐）

1. `price_structure_fetch_data`（拉日/周线数据）
2. `price_structure_analyze_direction`（判方向）
3. `price_structure_entry_signal`（找拐点）
4. `price_structure_risk_check`（风控）
5. `price_structure_run_sop`（端到端一键跑 1-4）

## 回测验证

在真实下单前，调用 `price_structure_backtest` 用历史数据验证：

- 沪金（AU）：乘数 1000
- 鸡蛋（JD）：乘数 10
- 生猪（LH）：乘数 16
- 默认成本：佣金 2.5 bps、最少 5 元、滑点 1 bps

输出：胜率、总盈亏、最大回撤、交易明细。
