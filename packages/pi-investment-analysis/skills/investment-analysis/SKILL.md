# Investment Analysis

- Separate observed market data from valuation assumptions.
- State discount rate, growth rates, terminal growth, horizon, shares, and as-of date.
- Never present a DCF output as a prediction or trading instruction.
- Use the technical signal as a descriptive indicator, not as an automatic order trigger.
- Preserve evidence IDs from the market-data Package in the analysis report.
