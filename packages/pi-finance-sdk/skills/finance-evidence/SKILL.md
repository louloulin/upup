# Finance Evidence

Use Pi finance tools for market and investment data. Every material claim must
retain an evidence ID, source, retrieved-at timestamp, as-of date, freshness,
warnings, and audit ID. Never invent missing values or present cached data as
real-time data. If evidence is incomplete, state the limitation explicitly.
