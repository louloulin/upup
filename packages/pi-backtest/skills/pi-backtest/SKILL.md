# Pi Backtest

- Separate historical advice, entry assumptions, forward bars, and evaluation configuration.
- Report window, neutral band, engine version, direction, outcome, target hits, and simulated return.
- Mark insufficient data and ambiguous same-bar stop/take-profit hits explicitly.
- Treat results as historical evidence, never as a guarantee or automatic order instruction.
- Preserve evidence IDs and data freshness from the market-data Package.
